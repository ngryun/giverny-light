# 지베르니의 빛

모네의 집을 1인칭 3D로 걸으며 빛과 색 퍼즐을 풀고, 빛 조각 여섯 개를 모아 빛의 문을 여는 방탈출 게임입니다. 고등학교 미술 수업 1차시(40~50분)에 맞춰 만들었습니다.

**바로 플레이:** https://ngryun.github.io/giverny-light/

## 수업에서 쓰기

- 대상: 고등학교 1~3학년, 개인 또는 2~4명 모둠(모둠당 기기 1대)
- 기기: 태블릿, 노트북, 스마트폰 브라우저. 설치할 것은 없습니다.
- 시작 화면의 **교사용 안내 · 정답**에 학습 목표, 수업 흐름, 방별 정답표가 있습니다.
- 탈출하면 이름, 걸린 시간, 사용한 힌트가 담긴 탈출 기록이 나옵니다. 캡처해서 제출하게 하면 됩니다.
- 진행 상황은 각 기기의 브라우저에 저장됩니다. 다음 반이 같은 기기를 쓸 때는 설정의 **처음부터 다시**를 눌러 주세요.
- 컴퓨터가 느리면 설정에서 **간단한 2D 화면**으로 바꿀 수 있습니다.

## 방과 퍼즐

| 방 | 퍼즐 | 배우는 것 |
|---|---|---|
| 현관 | 회색 안경으로 사라지는 숫자 찾기 | 인상주의라는 이름의 유래, 명도 |
| 살롱-아틀리에 | 모네의 팔레트 고르기, 그림자 색 섞기 | 검정 없는 팔레트, 보색과 색 그림자, 연작 |
| 노란 식당 | 판목의 맞춤 표시(겐토) 맞추기 | 우키요에 다색 목판, 자포니즘 |
| 파란 부엌 | 정원 문 비밀번호 | 물의 정원 조성(1893) |
| 모네의 침실 | 색 렌즈로 겹쳐 쓴 편지 읽기 | 모네의 백내장과 말년의 색 |
| 꽃의 정원 | 물러서서 색 점 속 글자 찾기 | 시각 혼합(색의 병치) |
| 물의 정원 | 수면 반영을 뒤집어 읽기 | 수평선 없는 화면, 수련 연작 |
| 수련 아틀리에 | 빛 조각을 색상환 순서로 끼우기 | 색상환, 오랑주리 대장식 |

## 사실과 이야기

게임 속 모네의 편지와 쪽지, 정원사 메모는 게임을 위해 지어낸 글입니다. 게임 안에서 '※ 실제로 남긴 말'로 표시한 인용만 실제 기록을 우리말로 옮기며 줄인 것입니다.

## 기술 메모

- 파일 하나(`index.html`)로 된 정적 웹 페이지입니다. 그림은 파일 안에 들어 있습니다.
- 3D는 [three.js](https://threejs.org/) r128을 cdnjs에서 불러오고, 글꼴은 Google Fonts를 씁니다. 그래서 인터넷 연결이 필요합니다.
- WebGL을 쓸 수 없는 브라우저에서는 자동으로 2D 화면으로 열립니다.
